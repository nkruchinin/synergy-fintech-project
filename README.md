# Учёт платежей и задолженности клиентов ООО «Эксперт-Про»

Программа выполнена в рамках производственной практики (эксплуатационная
практика) на базе ООО «Эксперт-Про».

**Кейс-задача № 3.** Разработать программное обеспечение для проекта,
связанного с финансовыми технологиями. Программа адаптирована под организацию
прохождения практики и предназначена для учёта платежей и задолженности
клиентов ООО «Эксперт-Про»: управляющих компаний, ресурсоснабжающих
организаций и ТСЖ.

Программа позволяет:

- вести сведения об организации-клиенте: название, ИНН, тип и тариф;
- закрывать расчётный период с фиксацией количества лицевых счетов;
- рассчитывать начисление по формуле «тариф × количество лицевых счетов»;
- регистрировать частичные, полные и авансовые платежи;
- автоматически относить переплату в аванс организации;
- распределять платеж в первую очередь в самый ранний неоплаченный период;
- выводить задолженность по периодам, просрочки и итоговое сальдо клиента.

## Структура решения

```
synergy-fintech-project
├── Application/
│   └── ReceivablesService.cs  — правила начисления, оплаты и расчёта долга
├── Infrastructure/
│   └── JsonDataStore.cs       — сохранение данных в JSON
├── Models/
│   └── ReceivablesModels.cs   — клиент, начисление, платёж и статус долга
├── Program.cs                 — консольное меню и пользовательские сценарии
└── FinTrack.csproj            — файл проекта .NET
```

При закрытии периода программа сохраняет число лицевых счетов и тариф,
действовавшие на этот момент. Поэтому изменение тарифа в последующем месяце не
меняет начисления за уже закрытые периоды.

## Основные сценарии

- Организация выбирается по номеру из списка либо по ИНН.
- Если платёж превышает остаток начисления, остаток суммы автоматически
  записывается как аванс.
- В отчёте начисления выводятся внутри блока организации по периодам; далее
  отображаются аванс и итоговая задолженность или переплата.

## Запуск

Требуется [.NET SDK 8.0](https://dotnet.microsoft.com/download).

```
dotnet run --project FinTrack.csproj
```

## Пример работы

```
Эксперт-Про — учет платежей и задолженности клиентов

1 — добавить организацию-клиента
2 — изменить тариф организации
3 — закрыть расчетный период и начислить плату
4 — зарегистрировать оплату
5 — отчет по задолженности и просрочкам

ООО «ТеплоРесурс» (РСО), ИНН 1000000002
  10.2026 | лицевых счетов: 850 | долг: 8 330,00 ₽ | ПРОСРОЧЕНО
  Итого задолженность организации: 8 330,00 ₽
```
