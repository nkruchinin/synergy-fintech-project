# Архитектура

Приложение построено по слоям.

- `Models` хранит сущности организации, начисления, платежа и статуса задолженности.
- `Application` реализует правила начисления, распределения платежа и расчета сальдо.
- `Infrastructure` загружает и сохраняет данные в JSON.
- `Program.cs` предоставляет консольное меню.

При закрытии периода создается отдельное начисление с числом лицевых счетов и тарифом на эту дату. Поэтому изменение тарифа или количества лицевых счетов не меняет историю. Платеж сначала погашает выбранное начисление; его превышение сохраняется как аванс по организации.
