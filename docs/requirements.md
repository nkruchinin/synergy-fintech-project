# Требования к учебному прототипу

## Назначение

Система предназначена для учета начислений, оплат и задолженности организаций-клиентов ООО «Эксперт-Про»: управляющих компаний, ресурсоснабжающих организаций и ТСЖ.

## Функциональные требования

1. Ведение организации с названием, ИНН, типом и тарифом за один лицевой счет.
2. Закрытие расчетного периода с фиксацией количества лицевых счетов на дату закрытия.
3. Расчет начисления как произведения тарифа и количества лицевых счетов.
4. Регистрация частичной, полной или авансовой оплаты.
5. Автоматическое направление превышения платежа в аванс организации.
6. Отчет по периодам с выделением просроченных начислений, авансов и итогового сальдо организации.

## Нефункциональные требования

- денежные суммы рассчитываются типом `decimal`;
- для каждого периода сохраняется тариф, применявшийся при начислении;
- данные сохраняются локально в JSON с временным файлом при записи;
- учебная версия использует только обезличенные демонстрационные данные.
